### 3. 待办中心
- `GET /dashboard/todos` → `TodoVo`：三类来源聚合（商机 nextTime 到期、线索距 7 天回收阈值 <=3 天、合同分期到期），按 urgency（0 逾期/1 今天/2 三天内）+ dueTime 排序。
- **只读聚合，不建待办表**：待办是算出来的，永远不会与实际状态不一致。
- 合同部分 urgency 按**自然日**判断（`LocalDate.isBefore/isEqual`），不能用 `atStartOfDay()` 与 now 比，否则当天到期会被误判为逾期。

- 分期拆单：前 n-1 期 `divide(periods, 2, DOWN)`，最后一期承担尾差，保证各期之和严格等于合同金额（10000/3 → 3333.33+3333.33+3333.34）。

**踩坑记录（重要）**：
1. **根目录 `qk-parent` 无法改名**——占用者不是 IDEA，而是 WorkBuddy 自己的 CLI 进程，它以 `E:/HeimaSoft/ideaProjects/qk-parent` 作为 workspace/cwd 启动。只要该会话存活，Windows 就报 `Device or resource busy`，任何工具都绕不过。**必须关闭 WorkBuddy 后在外部执行 `ren qk-parent sharp-crm`**。
2. 重命名前端目录前必须先杀 vite dev（`[::1]:5173`，netstat 用 IPv6 地址，只 grep `:5173` 带空格会漏）；否则目录被 node 进程占用。
3. 后端用 `nohup java -jar &` 启动会在命令结束时被回收，必须用后台任务方式（run_in_background）启动才持久。
4. 登录令牌走 **`token` 请求头**（非 `Authorization: Bearer`），`LoginInterceptor` 读 `request.getHeader("token")`。

**重启方式（改名后）**：`java -jar sharp-crm-management/target/sharp-crm-management-1.0-SNAPSHOT.jar`；`cd nginx-1.24.0-sharp && ./nginx.exe -g "daemon off;"`。

## 目录结构重构：backend / frontend / ops 三层

**新结构**：
- `backend/`：`pom.xml` + `sharp-crm-common/entity/management`（Maven 多模块整体下沉，模块间相对路径不变）
- `frontend/`：原 `sharp-web` 整体改名
- `ops/`：`Dockerfile`、`docker-compose.yml`、`docker/nginx.conf`、`nginx/`（原 nginx-1.24.0-sharp）、`sql/`（原 Sql表）、`scripts/`、`docs/`
- 根目录只留 `README.md`、`RESUME.md`、`.github/`、`.gitignore`、`.dockerignore`

**联动改动（缺一即断）**：
1. CI：backend job 加 `defaults.run.working-directory: backend`，产物路径 `backend/sharp-crm-management/target/*.jar`；frontend job 改 `frontend`。
2. Dockerfile 移到 `ops/`：`COPY backend/...`，`mvn -f backend/pom.xml`；compose 的 build 改为 `context: ..` + `dockerfile: ops/Dockerfile`，卷路径 `./sql`、`./nginx/html`。
3. `.gitignore` 改 `frontend/node_modules`、`frontend/dist`，新增 `ops/nginx/logs|temp`；`.dockerignore` 同步。
4. README 工程结构树与 4.2~4.7 全部命令改为新路径。

**验证**：`cd backend && mvn clean package` 30 单测全绿；`cd frontend && npm run build` 通过并部署到 `ops/nginx/html`；后端与 nginx 从新路径启动，健康检查 UP，7 个核心接口 200。

**易错点**：`mkdir frontend` 后再 `mv sharp-web frontend` 会变成 `frontend/sharp-web` 嵌套，必须先 `mkdir` 再移「目录内容」或直接 `mv sharp-web frontend` 且不预先建空目录。
